# Проект: E-commerce Shop

Учебный проект на Python, моделирующий базовую структуру бэкенда для интернет-магазина.  
Проект включает в себя реализацию классов для работы с товарами и категориями, а также систему автоматического подсчета количества объектов.

## Функционал

- **Класс Product**: описывает товар (название, описание, цена, количество).
- **Класс Category**: группирует товары. Хранит список товаров, название категории и описание.
- **Подсчет статистики**: автоматический подсчет общего количества категорий и продуктов при их создании.
- **Класс Smartphone**: наследует `Product`, добавляет специфические атрибуты для смартфонов, такие как производительность, модель, объем памяти и цвет.
- **Класс LawnGrass**: наследует `Product`, добавляет атрибуты для газонной травы, такие как страна происхождения, срок прорастания и цвет.
- **Метод add_product**: добавление продуктов в категорию с проверкой типа.
- **Метод new_product**: создание нового продукта или обновление существующего.

## Модули

### Модуль `abstracts`

Модуль **abstracts** содержит абстрактные классы, которые обеспечивают основу для других классов проекта. Эти абстракции позволяют создавать универсальные структуры для товаров и категорий, что помогает избежать дублирования кода и повысить читаемость.

- **Класс BaseProduct**: Абстракция для всех типов продуктов. Включает общие атрибуты, такие как `product_name`, `product_description`, `price`, `quantity`. Наследуется всеми классами, представляющими товары.
  
- **Класс BaseCategory**: Абстракция для всех типов категорий. Хранит информацию о категории, ее названии и связанных с ней товарах. Используется для удобной работы с категориями.

### Модуль `micsim`

Модуль **micsim** реализует классы и методы для моделирования различных ситуаций в магазине, таких как симуляция заказов, проверки наличия товаров и вычисление цен. Этот модуль помогает тестировать функциональность бэкенда.

- **Класс MixsimLog**: Класс для ведения логов во время симуляции. Он отслеживает действия, происходящие в системе, и записывает данные о состоянии заказов, продуктов и категорий в процессе работы.
  
- **Метод simulate_order**: Метод для симуляции оформления заказа. Используется для проверки правильности работы всех бизнес-логик, связанных с покупкой товара.

### Модуль `orders`

Модуль **orders** занимается обработкой заказов. Он включает классы и методы для оформления и управления заказами пользователей, а также для вычисления итоговой стоимости и возможных скидок.

- **Класс Order**: Класс, представляющий заказ. Содержит атрибуты, такие как список продуктов, дата заказа, информация о пользователе, статус заказа.
  
- **Метод add_order**: Метод для добавления нового заказа. Проверяет наличие товаров и их количество, а также вычисляет стоимость заказа.
  
- **Метод calculate_total**: Метод для вычисления общей стоимости заказа с учетом возможных скидок, налогов и доставки.
